# Docs Index & Conventions

> The index of skkuverse-miniapp's documentation, and how to write it. Read this before starting a new document.

## Folder structure (Diátaxis)

Documents are filed under the [Diátaxis](https://diataxis.fr/) categories, the same way skkuverse-app and skkuverse-server file theirs. **The category follows the reader's need, not the subject matter.**

| Folder | Need | Contents |
| --- | --- | --- |
| `tutorials/` | Learning | A guided first run for someone with no context. <!-- docs-gen:begin folder-state folder=tutorials -->None yet<!-- docs-gen:end folder-state --> |
| `how-to/` | Doing | A runbook for one goal |
| `reference/` | Looking up | Contracts and specs |
| `explanation/` | Understanding | Why something is shaped this way |
| `decisions/` | — | ADRs, `NNNN-kebab-title.md` |

A document serves one need. When a procedure and its background start sharing a page, split them and link the halves.

Knowledge local to one package belongs in that package's `README.md`, which is also its npm page.

## Writing rules

- **Frontmatter.** Start from [`_template.md`](_template.md). The keys are `title`, `type`, `status` (`draft`, `accepted`, `superseded`, `deprecated`), `owner`, `last-updated` (ISO date) and `audience` (`internal`, `public`).
- **Language.** Everything under `docs/`, plus `README.md` and `CLAUDE.md`, is English. Korean that is product copy carries a `<!-- conventions:allow-korean: reason -->` marker on its line.
- **Names.** Use kebab-case file names.
- **No copied values.** Point at the file that owns a value rather than copying it. For example, point at `packages/miniapp/src/protocol/messages.ts` rather than restating a limit.
- **Checks.** `pnpm lint:md` runs markdownlint with the fleet's rules, locally and in CI. `pnpm --filter repo-checks test` runs the conventions (frontmatter, language, folder names) from `packages/repo-checks/vendor/lint_conventions.py`, from this clone alone, and the drift check below.
- **Copied files.** `_template.md` and `../.markdownlint.jsonc` began as copies of the fleet's files, and this repository edits them now. `packages/repo-checks/vendor/lint_conventions.py` is different. It is a byte-identical copy of skkuverse-server's `.github/contract-tools/exported/lint_conventions.py`, so a fix goes to that file first and is copied back here whole, and nobody edits it here.
- **Generated parts.** A value the code, a workflow or a manifest owns is written by `pnpm docs:gen` between two `docs-gen` comments, which GitHub hides. The API reference under `reference/api/` is generated by TypeDoc, and the index below is generated from each document's frontmatter and opening quote. Never edit a generated part by hand. `pnpm --filter repo-checks test` fails with "Docs are out of date" when one differs from what the generator writes, and CI runs it.
- **Audience.** The docs site publishes every document, whatever its `audience` says, because this repository is public. `audience` records who a document is written for, and does not hide it.
