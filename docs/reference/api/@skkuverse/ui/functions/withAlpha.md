# Function: withAlpha()

> **withAlpha**(`color`, `alpha`): `string`

Apply an alpha to a `#RGB` or `#RRGGBB` colour. Non-hex input is returned unchanged.

## Parameters

### color

`string`

### alpha

`number`

## Returns

`string`
