# Variable: HAIRLINE

> `const` **HAIRLINE**: `1` = `1`

React Native's `StyleSheet.hairlineWidth` is the thinnest line the device can
draw. The browser equivalent is one CSS pixel, which a high-density display
already renders as a sub-pixel line.
