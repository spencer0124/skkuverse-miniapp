# Type Alias: ParagraphFontWeight

> **ParagraphFontWeight** = `"regular"` \| `"medium"` \| `"semibold"` \| `"bold"`

The web system's weight vocabulary. Narrower than SDS's `FontWeightKeys`, and
spelled `semibold` rather than `semiBold`.
