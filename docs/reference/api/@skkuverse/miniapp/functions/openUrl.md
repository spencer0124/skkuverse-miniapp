# Function: openUrl()

> **openUrl**(`url`, `options?`): `void`

Open `url` outside this page: through the app inside it, in a new tab outside it.

## Parameters

### url

`string`

### options?

[`OpenUrlOptions`](../interfaces/OpenUrlOptions.md) = `{}`

## Returns

`void`
