# Type Alias: Chrome

> **Chrome** = `"glass"` \| `"opaque"`

- `glass`: the app's header and bars are translucent Liquid Glass (iOS 26+),
  so a background painted beneath them shows through, blurred.
- `opaque`: they are solid (earlier iOS, Android); nothing beneath shows.
